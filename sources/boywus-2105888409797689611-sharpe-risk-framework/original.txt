我爱夏普的那些年

一个 Sharpe 300 的策略，到底意味着什么？如果它意味着“比 Sharpe 3 的策略好一百倍”，那显然荒唐；如果不是，那 Sharpe 到底在衡量什么？为什么总是能看到别人甩出很高 Sharpe 的高频策略？

初识夏小姐

刚刚研究量化交易的时候，老板们总是问我，你策略的夏普多少，从刚刚开始的懵懂无知，到我也开始用夏普衡量我的业绩标准，一步一步确信这是我努力的方向，像极了当年她PUA我说赚到多少钱就不辜负我一样。

Sharpe Ratio 的定义其实非常简单：

Sharpe =（策略平均收益率 - 无风险收益率）/ 收益率标准差

分子是超额收益，就是你算的策略平均收益率 - 无风险收益率，就是你减去国债这种理论无风险后的策略收益率。

分母是收益率的标准差。它想表达的东西也很朴素：为了获得这些超额收益，你承受了多少收益波动，但是实际上大家都近似理解为行情波动导致的收益率波动。

从这个意义上说，Sharpe 本身并没有什么问题。问题往往出现在我们开始把它继续解释成“策略有多好”“策略有多安全”“风险调整后收益有多高”，甚至拿两个 Sharpe 数字直接做高低比较的时候。

因为从这一刻开始，我们其实默认了很多公式里没有写出来的东西：这些收益是不是独立的，收益分布是不是稳定的，波动率升高以后策略本身还会不会继续赚钱，两个策略用的是不是同一把尺子，以及这条漂亮的收益曲线背后，到底承担了什么风险。

而高频交易，恰好会把这些问题全部放大。



高频中虚胖的夏小姐

如果 Sharpe 3 已经算得上一个很漂亮的策略，可在高频交易里，看起来离谱的数字并不少见，几十、上百，甚至更高。尤其当收益按照成交、秒级或者更细的频率统计，再机械地年化以后，Sharpe 很容易迅速膨胀。

这就产生了一个很奇怪的问题：如果 Sharpe 不能直接理解成“策略好坏的倍数”，那这个数字到底在衡量什么？

Sharpe 从日频变成年化时，最常见的做法是：

年化 Sharpe = 日频 Sharpe × √252

分钟级、秒级甚至成交级也是类似，按照一年里有多少个观测值，再乘上对应的 √N。

这个算法背后有一个很强的隐含条件：每一次收益观测之间近似独立，而且来自相对稳定的同一个分布。

如果我每天获得 252 次互相独立的赌博机会，那么把样本数量增加 252 倍以后，期望收益线性累积，而标准差只按照平方根增长：

总期望收益 = N × 单期平均收益

总波动 ≈ √N × 单期波动

因此 Sharpe 自然增加：

因此，年化 Sharpe ≈ 单期 Sharpe × √N

这也是 √N 年化的来源。

问题是，高频里的成交远远没有这么独立。

比如一个大卖家开始连续砸盘，我在买盘上连续接到了 300 笔。数据库里会留下 300 条 fill，每一条都可以计算一次 markout，看上去像是有了 300 个样本。

但从经济意义上看，这 300 笔可能根本不是 300 次独立事件。

它们可能只是：同一个人、同一股 order flow、同一个市场状态，花了一段时间，把单子分拆了给我成交而已

于是：

N_observed = 300

但真正的：

N_effective << 300

你只是把同一个风险事件切成了很多份。

高频里这个问题还会因为 markout horizon 重叠而变得更加明显。

为了好算，比如我每 1ms 成交一笔，然后计算每笔成交之后 1 秒钟的 markout。

那么连续 1000 笔成交的观察窗口其实是高度重叠的：

[t, t+1s]

[t+1ms, t+1.001s]

[t+2ms, t+1.002s]

……

这些所谓的 1000 个收益样本，大部分时间都在观察同一段价格运动。

如果这一秒市场上涨，可能 1000 个 markout 一起变好；如果这一秒市场暴跌，也可能一起变坏。

数据库看起来拥有 1000 个 采样点，实际上可能只是对同一秒行情拍了 1000 张照片。

这也是为什么高频特别容易算出夸张的 Sharpe。

假设每笔交易的平均收益只有：

平均每笔赚 1bp

单笔标准差：

单笔收益标准差 2bp

那么单笔 Sharpe 只有：

单笔 Sharpe = 0.5

如果一天做 10000 笔，一年按照 252 天机械年化：

年化 Sharpe = 0.5 × √(10000 × 252) ≈ 794

一个 Sharpe 接近 800 的策略就这么诞生了。

数学公式本身并没有算错，问题是你偷偷假设了一年拥有：

2,520,000

次互相独立的赚钱机会。

实际上你可能只是经历了几千个、几百个甚至更少的有效市场事件，只不过每个事件里成交了很多次。

严格一点来说，只要相邻收益之间存在相关性，累计收益的波动就不再只是“单期波动 × √N”。除了每一期自己的波动，还要把不同时间之间的相关性一起算进去。

只有当这些相关性接近 0，也就是各期收益近似独立时，我们熟悉的 √N 年化才漂亮成立。

所以这一层并不是说 Sharpe 本身错了，而是高频交易特别容易把：

采样次数

误认为：

独立风险事件的次数。

一分钟只发生了一件事，你却因为成交了 500 次，把它记成了 500 次经验。

明明她只是暑假没地方去，陪你待了一个月，你却认为她好像爱了许久许久，误认为每一天她都在独特地爱着你。

因此一个成交级 Sharpe 300，首先说明的可能不是策略有多优秀，而只是说明：

你把同一段市场风险切得足够碎。

当然，这个问题并不是无解。

最简单粗暴的办法，就是把收益降采样到更长的时间尺度，比如直接用真实的 daily realized PnL，再对自相关进行修正。至少这时候“一天成交十万次”不会凭空变成十万个独立样本。

可惜的是，当我们把这个最明显的统计问题修掉以后，Sharpe 更麻烦的问题才刚刚开始。

因为即使每天只记一个 PnL，也仍然默认了一件更危险的事情：

今天的赚钱方式，和暴风雨来临时的赚钱方式，是同一种东西。



夏小姐只看见了波动

把成交级收益降采样成 daily realized PnL 以后，前面那个“虚胖”的问题确实缓解了不少。

一天不管成交十次还是十万次，最后只记一个真实 PnL，再用日收益率计算 Sharpe，至少不会因为交易频率高就凭空多出几百万个“独立样本”。

但这只能解决统计尺度的问题，没有解决一个更根本的问题：

Sharpe 默认拿一个固定的均值和一个固定的标准差，去概括整个策略。

也就是我们很容易把策略想象成：

收益 = 稳定的 μ + 随机噪声

其中 μ 是策略稳定提供的超额收益，而 ε 只是市场噪声。

市场越乱，无非就是噪声波动 ↑，收益曲线抖得更厉害一点。

但真实交易往往不是这样。

尤其对于做市、套利、carry 这类策略来说，市场状态变化以后，变化的不只是波动率，连你原本赖以赚钱的东西本身都会变化。

更准确一点，真实的策略更像：PnL = f(波动率、spread、depth、toxicity、inventory、latency……)

也就是说，收益不是一个常数加噪声，而是市场状态的函数。

拿最简单的 maker 来说。

在平静市场里，我挂在 bid 和 ask 两边，正常获得：

spread + rebate

价格缓慢运动，库存来得及回转，对冲市场深度也足够，这时候做市本身可能拥有稳定正收益。

但当市场波动率突然升高以后，发生的并不是简单的：

“以前每天赚 100，现在还是平均赚 100，只不过每天上下多抖一点。”

而更可能是：

对手盘的信息含量变高

adverse selection 变严重

一侧订单开始连续成交

inventory 快速向单边堆积

hedge price 在你成交以后继续跑

hedge venue 的 depth 同时下降

slippage 和 latency cost 一起增加

这时候连你的期望收益都会发生变化。波动率变了，策略的预期收益也会跟着变。

更麻烦的是，这个关系往往还不是线性的。

波动率从 10 涨到 20，可能只是让你少赚一点；但从 50 涨到 100，可能直接让整个策略的盈利机制反过来。

而且这种关系往往不是线性的，越到极端状态，恶化得越快。

这就是我觉得 Sharpe 最容易让人产生误解的地方。

它的分母写着一个 σ，于是很容易让人潜意识里认为：

波动率就是“风险”，收益就是“收益”，二者各自独立，最后拿来相除。

但在真实交易里，风险状态本身可能正在侵蚀你的收益来源。

更准确地说，是 μ = μ(σ)。

当 σ 改变的时候，分母在变，分子也在变。

甚至二者可能朝着最糟糕的方向同时变化：σ ↑，μ ↓；如果进入极端状态，甚至会变成 μ < 0。

那么这时候已经不能理解成“Sharpe 下降了”。

而应该理解成：

这个策略已经换了一种赚钱方式，甚至已经不赚钱了。

所以 daily Sharpe 即使统计得完全正确，也只能告诉你：

在过去这些市场状态混合起来以后，平均收益与平均波动之间是什么关系。

它并不会告诉你：低波动环境下的 E[PnL]，和高波动环境下的 E[PnL]，分别是什么。

但对于真正的风险管理来说，后者显然更重要。

因为你并不是特别担心一个平静星期五下午策略少赚了 20%。

你真正担心的是：

当市场进入某种极端状态以后，这个策略到底会变成什么东西。

这也是为什么很多看起来 Sharpe 极高的策略，本质上都带有一点“卖保险”的味道。

平时不断收到 +1、+1、+1、+1、+1，偶尔出现一次 -50，甚至 -100。

如果那一天还没有来到，那么历史 Sharpe 会漂亮得非常稳定。

但这种稳定并不一定意味着你找到了稳定 alpha，也可能只是说明：

你每天都在收取某种风险溢价，而真正需要赔付的时候还没到。

就好像她没离开你的每一天，你骑电动车接她的每一天，给她买花，带她喝蜜雪冰城，只不过是这个状态下的暂时截面罢了。

这时候我们就会看到 Sharpe 的下一个问题：它甚至不区分赚钱的波动和亏钱的波动。



夏小姐眼里的上涨和下跌是同一种痛苦

Sharpe 的分母是收益率标准差，而标准差只关心一件事：

收益离平均值有多远。

所以 +5% 和 -5%，对于标准差来说，本质上是对称的。

但对于一个真实交易者来说，两者显然不是一回事。

如果一个策略偶尔突然多赚 10%，我们一般不会抱怨：

今天风险太大了，居然向上偏离均值这么多。

但 Sharpe 会。

在它的计算里，这种“好波动”同样会增加分母，从而降低 Sharpe。

这也是为什么后来会出现 Sortino Ratio。

Sortino 的想法很直接：既然我们真正讨厌的是下跌，那为什么要把上涨也当成风险？

于是它把总标准差换成 下行标准差：

Sortino =（平均收益 - 最低可接受收益）/ 下行标准差

其中 最低可接受收益率标记为MAR，分母只统计低于这个目标的收益波动。

这样至少解决了 Sharpe 一个非常直观的问题：

不再把意外多赚钱和意外亏钱当成同一种风险。

对于那些收益明显不对称的策略，Sortino 通常比 Sharpe 更符合人的直觉。

但它也只是修补了一层表面。

因为假设一个策略过去两年一直：

+1、+1、+1、+1、+1……

真正的结构却是：

+1、+1、+1……最后来一个 -100

而最后那个 -100 恰好还没有发生。

那么它不仅 Sharpe 很高，Sortino 一样会高得离谱。

历史上没有 下行样本，自然也就没有 下行标准差。

所以负偏度真正麻烦的地方，不只是“Sharpe 把上涨和下跌一起算进标准差”。

更深一层的问题在于：

历史收益分布只是 payoff 结构已经兑现出来的结果，并不是 payoff结构本身。

一个 short gamma、short vol、short liquidity 的策略，可以在很长一段时间里表现得像一个低波动、高 Sharpe、高 Sortino 的完美策略。

直到市场终于走到那个它最不希望出现的位置。

这时候再回头看，我们才会发现：

原来以前那条平滑的收益曲线，不是没有风险，只是风险一直没有被结算。

不像她，她只会觉得和你待在一起是下行区间，以后的路，只要离开你，都是上行。



夏小姐只看表面的工资单

前面说到 short gamma、short vol、short liquidity，这里就碰到了另一个很容易被混淆的问题。

Sharpe 看的是结果：一串已经发生过的收益，然后把它们压缩成“平均超额收益 / 收益波动”。

但它并不知道这些收益到底是怎么来的。

两个 Sharpe 都等于 3 的策略，背后的结构完全可能不同。

策略 A 可能是真的拥有某种预测优势：PnL ≈ alpha + noise。

策略 B 可能只是长期卖波动：PnL ≈ premium - tail loss。

策略 C 甚至可能只是一直加杠杆承担一个平时很少兑现的风险。

历史收益曲线长得很像，并不意味着它们是同一种策略。

这时候只看 Sharpe，就有点像只看一个人的工资流水，却不问他的工作是什么。

一个人每个月稳定收 3 万，可能是工资，也可能是在卖保险，也可能是在借钱周转。

银行流水都很平滑，但经济含义完全不同。

所以实际交易里，我们往往还需要看另一组东西：Delta、Gamma、Vega，以及更一般的因子暴露和一阶、二阶敏感度。

它们回答的问题和 Sharpe 完全不一样。

Sharpe 问的是：

过去这段时间，你赚得稳不稳？

而这些 指标问的是：

如果接下来市场发生变化，你的仓位会怎么响应？

比如一个策略历史 Sharpe 很高，但：

Gamma < 0

那意味着价格剧烈运动的时候，它可能天然越来越难受。

如果：

Vega < 0

那波动率上升本身就可能伤害它。

如果盈利高度依赖盘口深度，你可能还带着 short liquidity；如果赚钱依赖两个市场长期高度相关，那还可能隐含协同失效风险。

这些东西不会自动出现在 Sharpe 里。

所以严格来说，“Sharpe 不算 Delta、Gamma、Vega”并不是 Sharpe 的错误。

因为它本来就不是干这个的。

真正的问题是：

我们经常看到一个高 Sharpe，就下意识把它解释成“风险很低”。

一个策略过去非常平滑，只能说明：

过去那些市场状态没有把它最脆弱的那一面逼出来。

并不能说明：它没有脆弱的一面。

她并不那么关心你现在怎么赚到钱的，以后还赚不赚钱，只关心这个工资单是否能够养活她读完研究生。



最危险的往往是还没见过的样本

这也引出了历史指标最尴尬的一件事：

没发生过的事情，它就当不存在。

假设一个策略每天都能稳定赚一点钱，但同时存在这样一个隐藏结构：灾难发生概率只有 0.1%，但一旦发生，PnL = -80%。

如果你过去三年都没有碰到那 0.1%，那么历史收益率里根本不会出现这一项。

于是你的 Sharpe 很漂亮。

Sortino 也很好看。

最大回撤可能也很漂亮。

原因很简单：

那个真正危险的状态根本没有进入样本。

很多策略最容易犯的错误，就是把从未见过的事情误认为 impossible。

美股历史上只熔断过5次，四次都发生在2020年的3.12附近的行情，那一年我失去了很多，只能躺在家里发呆。

尤其在交易里，很多真正致命的问题天然就是低频事件：

交易所宕机

对冲腿突然失去流动性

两个长期高度相关的市场突然脱钩

价格直接 gap

市场进入单边行情

原本稳定的 funding、basis 或 借贷机制突然变化

平时“肯定能成交”的盘口瞬间消失

这些风险不一定能靠多算几个统计指标解决。

因为所有基于历史收益分布的东西，本质上都需要一个前提：

这个风险至少曾经以某种形式出现在历史里。

VaR指标可以看尾部。

Expected Shortfall 指标可以看超过 VaR 之后，平均还会亏多少。

最大回撤可以看过去最惨的时候。

Sortino 可以只惩罚 downside。

但如果真正的问题是：

未来会出现一个历史上从未出现过的状态，

那这些指标全部会遇到同一个天花板。

这时候只能换一种思路：不再问“历史告诉我会亏多少”，而开始问：

如果我主动把世界改坏一点，这个策略会让我有多惨？

比如把流动性压到原来的 0.1 倍，把 波动率 放大到 3 倍，把对冲延迟增加 500ms，或者直接把双品种协同度 从 0.95 打到 很低的值。

甚至直接假设：

对冲市场暂时消失。

这就是 压力测试 存在的意义。

它们只是在承认一件很朴素的事实：

历史不是风险的全集。

所以我现在越来越觉得，Sharpe 最大的问题不是它没有包含所有风险。

这本来也不可能。

真正危险的是人很容易看到一个漂亮的历史 Sharpe，就产生一种错觉：

这些风险已经被统计过了。

其实未必。

有些风险只是还没轮到你。



夏小姐会用不同的尺子衡量世界

再往下还有一个更现实的问题。

我们经常会说：

“这个策略 Sharpe 5。”

但严格来说，这句话本身的信息量其实很低。

至少还应该继续问：

你这个收益率是怎么算的？

因为同样一个 PnL，可以除以 Equity，可以除以 Margin，也可以除以 Gross Exposure；如果是高频，甚至还会用 Markout / Fill Notional。

它们数学上都可以叫“收益率”，但经济意义完全不同。

100 万资金，20 万保证金，500 万 gross notional。

今天赚 1 万。按不同分母，你可以说赚了 1%，也可以说赚了 5%，甚至按照成交 notional 算出来可能只有几个 bp。

然后再拿这些收益率去算 Sharpe，得到的数字当然也不一样。

历史样本足够长

策略确实拥有一个很漂亮的 Sharpe

还有一个很现实的问题：

这个策略到底能放多少钱？

假设有两个策略：A 的 Sharpe = 10，B 的 Sharpe = 3。

乍一看，A 好像明显优于 B。

但如果 A 最多只能放 100 万美元，再往上加仓，自己的订单就开始吃掉盘口、推高滑点，最后 edge 消失；

而 B 可以稳定承载 10 亿美元

那从真正的经济价值来看，两者根本不是一个维度上的东西。

Sharpe 本身对此完全没有意见。

因为它本来就是一个无规模指标。

理论上，如果一个策略的收益和风险都可以完全线性放大，那么加两倍杠杆以后，收益翻倍、波动也翻倍，二者在 Sharpe 里正好抵消，所以 Sharpe 不变。

这其实正是它设计上的优点：把策略本身的收益质量和单纯的杠杆倍数分开。

但现实交易并不会无限线性。

尤其高频交易里，当仓位 Q 增大以后，往往会同时出现：slippage ↑、market impact ↑、fill quality ↓、hedge cost ↑，最后 edge ↓。

所以真实世界里的 Sharpe，其实更像是 Sharpe(Q)：它本身也会随着规模变化。

一个在 10 万美元规模上 Sharpe 20 的策略，可能到了 1000 万美元以后只剩 Sharpe = 5，再到了 1 亿，Sharpe ≈ 0。

这时候讨论“这个策略 Sharpe 20”就又缺少了一块非常重要的信息：

在哪个规模上？

这也是为什么真正做策略的时候，我会同时关心 PnL / Capital、PnL / Margin、PnL / Turnover，以及规模继续增加时，PnL 和 edge 到底怎么衰减。

因为对于一个策略来说，Sharpe 很高当然令人开心，但如果只能塞进去几千美元，那它更像是一张漂亮的收藏卡。

反过来，一个 Sharpe 没那么夸张、但是能承载巨大资金的策略，可能才是真正有商业价值的东西。

所以 Sharpe 回答的是：

单位波动下，历史收益有多高。

而 Capacity 回答的是：

这台机器到底能吞进去多少钱。

这两个问题不能互相替代。

然后她并不关心你的上限，她只会觉得穷小子在个二线城市，她想去日本看樱花，去土耳其坐热气球，一切的一切，都不包含你



夏小姐的永远迷人

还有一种 Sharpe，我觉得在量化里尤其容易被忽略。

假设我只研究一个策略，跑完回测 Sharpe = 3。

这当然很值得继续研究。

但另一种情况是，我测试了 1,000,000 种策略，最后从里面挑出了一个 Sharpe = 3。

这两个 Sharpe 3，显然不是一回事。

因为只要你不断试，总会有人长得很漂亮。

这和买彩票有点像。

一个人买一张彩票中了，不寻常；

一百万人各买一张，最后把那个中奖的人请上台讲“选号方法”，事情的味道就完全变了。

量化交易尤其容易发生这种事情。

因为我们可以不断调整：

feature

lookback window

threshold

entry condition

exit condition

TTL

quote distance

inventory coefficient

stop condition

regime filter

只要参数空间足够大，总会出现一批历史表现异常漂亮的组合。

然后人又很容易把其中最漂亮的那一个拿出来，说：Sharpe = 4.7。

问题在于，我们看到的是一大堆策略里最高的那个 Sharpe，而不是一个随机挑选策略的 Sharpe。尝试次数 N ↑，这个最大值天然也会越来越高。

所以一个漂亮的 Sharpe，还应该继续问一句：

你试了多少次才找到它？

这其实和前面的高频采样形成了一个很有意思的对称。

高频采样的问题是观测次数 ↑，让你误以为自己拥有更多独立证据；而策略挖掘的问题是尝试过的策略数量 ↑，让你更容易碰巧找到一个漂亮结果。

所以：

高 Sharpe 既可能来自高频采样，也可能来自高频试错。

这也是为什么后来会有 Probabilistic Sharpe Ratio、Deflated Sharpe Ratio 这一类东西。

它们试图回答的不再只是：

你观察到的 Sharpe 是多少？

而是：

考虑样本长度、收益分布，以及你做过多少次选择以后，这个 Sharpe 还有多值得相信？

这和传统意义上单纯计算“平均超额收益 / 收益波动”，已经是两件不同的事了。

尤其 AI 出现以后，这个问题反而可能越来越严重。

以前一个研究员一天只能试几十个想法。

现在一句：

“给我再生成 500 个特征组合。”

几分钟就能跑完。

而我去了很多地方，想找到她，却都只是像她

计算能力越强，搜索空间越大，越容易从噪声里挖出一个看起来像黄金的东西。

所以未来最不稀缺的，可能就是：

回测里很高的 Sharpe。

真正稀缺的是，你能解释它为什么存在，而且知道它什么时候会消失。



那夏普到底还有没有用？

绕了一大圈以后，很容易走向另一个极端：

既然 Sharpe 有这么多问题，那干脆别看了。

我觉得这同样不对。

Sharpe 其实一直都很诚实。

它从来没有承诺告诉你：

策略为什么赚钱

极端行情会怎么样

有没有 short gamma

能不能扛住交易所宕机

能放多少钱

有没有过拟合

下一次危机会不会爆掉

这些很多都是我们后来自己加给它的。

Sharpe 真正回答的问题一直都非常窄：

在你给我的这串历史收益率里，平均超额收益相对于收益波动有多大？

Sharpe 真正回答的，其实就这一件事。

如果你只是想快速比较一条收益曲线到底平不平滑，它当然很好用；但真实的风险管理，不可能只靠一个数字。

有的指标专门看下行风险，比如 Sortino；有的看尾部和极端亏损，比如偏度、峰度、Expected Shortfall；有的看路径，比如最大回撤和 Calmar；还有一些根本不是在看历史收益，而是在看你到底暴露了什么风险，比如 Delta、Gamma、Vega，以及各种压力测试。

再往后，还得问这个策略能不能放大，资金进去以后滑点、冲击成本、容量会不会把收益吃掉；甚至还要问，这个漂亮的 Sharpe 到底是真实优势，还是反复筛参数筛出来的偶然结果。

所以这些东西并不是为了寻找一个“比 Sharpe 更高级的万能指标”。

它们只是分别回答不同的问题。

风险本来就没有办法压缩成一个数字。

她把复杂性隐藏得太好了。
